Help & Guide / मदद और गाइड

Welcome / स्वागत है

यह आपकी pocket TA/DA sheet है। हर दिन आपने क्या किया (travel, food, lodging…) बस उसकी details यहाँ enter करें। App अपने आप सभी expenses calculate करेगा और आपके लिए print-ready PDF और Excel file तैयार करेगा। इसे आप phone या computer दोनों पर use कर सकते हैं। आपका सारा data आपके अपने device में ही रहता है: न कोई login, न कोई server।

Set up (पहली बार केवल एक बार)
1
अपनी details भरेंSetup → Employee profile खोलें। अपना Employee Code, Name, Department, Email, Location, Depot, Region और approver का नाम भरें। इसके बाद Fare & calculation में अपना per-km rate set करें।
2
अपने regular places add करेंSetup में ही उन markets और places को add करें जहाँ आप अक्सर जाते हैं। आप कोई पूरा route भी save कर सकते हैं, जैसे “Chhindwara, Seoni, Amla”। बाद में इन्हें type करने की जगह सिर्फ tap करके select कर सकते हैं।
हर महीने का काम
3
अपना month खोलेंClaim tab में जाएँ, Month और Year select करें और Open / Create पर tap करें। Sundays अपने आप fill हो जाएँगे, जिन्हें आप जरूरत पड़ने पर edit भी कर सकते हैं।
4
Daily entry add करें+ Add Daily Entry पर tap करें या Daily tab में किसी भी date को select करें। From और To time, distance (km में) और बाकी expenses enter करें। Travel amount, hours और पूरे दिन का total आपके type करते ही automatically update होगा।
5
अपना travel route चुनेंजिन places पर आप गए थे, उन्हें उसी order में tap करें। Arrows आपके route को दिखाएँगे। अगर किसी जगह दोबारा गए हैं, तो उस place को दो बार tap करें। किसी place के नीचे Add event… का use करके event attach कर सकते हैं। कोई नया place है? उसका नाम type करें और Add पर tap करें।
6
Holiday, Leave या Sunday mark करेंStatus में Holiday, Leave या Sunday select करके Save करें। ऐसे दिनों के लिए आपको कोई expenses enter करने की जरूरत नहीं है।
7
अपनी entry Save करेंSave पर tap करें। अगले दिन की entry पर जाने के लिए Save & next use करें। बाद में किसी भी date को tap करके उसकी entry edit कर सकते हैं। ‹ › buttons से पिछले या अगले दिन पर जा सकते हैं।
8
अपना total check करेंSummary tab में आपको सभी expenses का total और amount in words दिखाई देगा। ये सभी calculations आपकी daily entries से automatically होती हैं, इसलिए दोनों हमेशा आपस में match करेंगे।
9
अपना claim download करेंExport tab खोलें और Download PDF (एक A4 page) या Export Excel पर tap करें। अब इसे print करके sign कर सकते हैं या approval के लिए file भेज सकते हैं।
10
अपने data का Backup रखेंBackup tab में समय-समय पर Download Snapshot पर tap करके backup download करते रहें। अगर आप नए phone पर shift होते हैं, तो उसी backup file का use करके Restore कर सकते हैं।
कुछ सामान्य सवाल (Quick answers)
Travel amount कैसे calculate होता है?

Distance × Setup में आपका निर्धारित per-km rate। अगर किसी particular day के लिए अलग rate या amount रखना है, तो उस दिन की entry में override boxes का use करें।

अगर journey आधी रात के बाद तक चलती है तो?

From में 22:00 और To में 06:30 enter करें। App इसे overnight trip मानेगा और total duration 08:30 hours दिखाएगा।

मेरा data कहाँ store होता है?

आपका data केवल इसी device के इसी browser में store होता है। Browser data clear करने या Private/Incognito window use करने से आपका data delete हो सकता है। इसलिए समय-समय पर backup download करते रहें।

PDF या Excel button पर click करने से कुछ नहीं हो रहा?

Export tools पहली बार use करने पर internet से download होते हैं। अपना internet connection check करें और दोबारा try करें।

मैंने अपनी list से कोई place हटा दिया। क्या पुरानी entries सुरक्षित हैं?

हाँ। आपकी पुरानी entries में वही place names सुरक्षित रहते हैं, जिनके साथ उन्हें पहले save किया गया था।

सारा data हटाकर बिल्कुल शुरुआत से कैसे शुरू करें?

Backup tab → Clear all application data पर जाएँ। ध्यान दें, यह action undo नहीं किया जा सकता। इसलिए आगे बढ़ने से पहले अपना backup जरूर download कर लें।
